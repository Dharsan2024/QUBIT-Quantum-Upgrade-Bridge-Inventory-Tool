QUBIT is four layers over seven Python packages, drawn from the 171 real inter-package import statements rather than from a design document. Every runtime edge points downward; the 2 upward ones live in qubit-core/alembic/env.py and exist so Alembic sees all twelve tables under one metadata object, which is schema registration and not a runtime dependency. Note that qubit-cli reaches the engine packages directly rather than through the API, so a scripted run and a windowed run are not the same path. The desktop shell bundles the dashboard rather than serving it, and the engine binds to 127.0.0.1 — which is what makes the offline claim structural rather than a policy. Source: tables/T_imports.csv.
