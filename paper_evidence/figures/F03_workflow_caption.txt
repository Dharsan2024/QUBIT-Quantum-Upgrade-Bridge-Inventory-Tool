The pipeline, with the module that implements each stage and the artifact it leaves behind. Six independent discovery sources feed one normalised inventory, so a finding from a TLS handshake and a finding from an AST are the same kind of object by the time risk is computed. The loop is closed rather than open: a migration counts as complete only when a fresh scan no longer reports the finding, which is what stage 5 verifies. Every stage is local — no step contacts a network service the user did not name.
